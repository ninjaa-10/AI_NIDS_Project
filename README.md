AI-Based Network Intrusion Detection System

This project implements an AI-based Network Intrusion Detection System (NIDS)
using Machine Learning techniques to identify malicious network traffic.

   Dataset
CIC-IDS-2017 (Canadian Institute for Cybersecurity)

  Algorithm Used
Random Forest Classifier

  Features
- Real network traffic analysis
- Machine learning-based intrusion detection
- Streamlit web dashboard
- Live traffic simulation

 How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the application:
   streamlit run nids_main.py
